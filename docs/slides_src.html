Safety · built and tested

Four risks, each with a defense that's been tested

  • Injection: the scanner holds it back, entries reach the model only as escaped data, and tools are read-only. In a live attack with the scanner off, the provider blocked the blatant one and the model ignored the subtle one.
  • Invented memories: code verifies every quote against its entry.
  • Crisis: resources (988), never AI analysis, and Zoom Out pauses.
  • Spend: caps per run, per day and per agent.
